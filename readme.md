> Xiaohongshu (小红书 / RedNote) downloaders, crawlers, SDKs, and MCP servers.

Xiaohongshu is a major lifestyle and e-commerce social platform. This list curates software that helps people download content, collect data, build integrations, and automate creator workflows.

## Web Downloaders

Browser-based tools for saving Xiaohongshu videos, images, and albums.

- [XHS Downloader](https://xiaohongshudownloader.com) - Web downloader for Xiaohongshu videos, images, and multi-photo albums without requiring an account.
- [SeekIn](https://www.seekin.ai) - Multi-platform media downloader with Xiaohongshu support and optional audio extraction.
- [RedNote Downloader](https://rednotedownloader.com) - Web downloader focused on RedNote / Xiaohongshu videos and photos.

## Open Source Downloaders & Crawlers

Self-hosted tools for extracting links, downloading media, and collecting note data.

- [XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader) - CLI and GUI tool for extracting Xiaohongshu links and downloading works from accounts, searches, and collections.
- [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) - Multi-platform crawler with Xiaohongshu note and comment collection support.
- [Spider_XHS](https://github.com/cv-cat/Spider_XHS) - Xiaohongshu crawler oriented toward data collection and operations workflows.

## Libraries & SDKs

- [xhs](https://github.com/ReaJason/xhs) - Python client wrapping Xiaohongshu web APIs for notes, users, and related requests.

## MCP & AI

- [xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) - Model Context Protocol server for interacting with Xiaohongshu from AI agents.

## Browser Extensions

- [Xiaohongshu Video Downloader](https://chromewebstore.google.com/detail/xiaohongshu-video-downloa/ldhnoohmejgabngbbldjngpipcpcflmn) - Chrome extension for downloading Xiaohongshu videos from the browser.
- [Xiaohongshu for Desktop](https://chromewebstore.google.com/detail/xiaohongshu-for-desktop/kdbmbkoigckegcfgcfmfpdkbbnhjcooo) - Chrome extension that opens Xiaohongshu in a desktop-friendly window.
